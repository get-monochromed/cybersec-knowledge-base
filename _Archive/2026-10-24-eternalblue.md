# summary
**EternalBlue**[[5]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-ars-5) is a computer [exploit](https://en.wikipedia.org/wiki/Exploit_\(computer_security\) "Exploit (computer security)") software developed by the U.S. [National Security Agency](https://en.wikipedia.org/wiki/National_Security_Agency "National Security Agency") (NSA).[[6]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-:2-6) It is based on a [zero-day vulnerability](https://en.wikipedia.org/wiki/Zero-day_vulnerability "Zero-day vulnerability") in [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows "Microsoft Windows") software that allowed attackers to gain access to any number of computers connected to a [network](https://en.wikipedia.org/wiki/Computer_network "Computer network"). The NSA was aware of this vulnerability but did not disclose it to Microsoft for several years, as it intended to use the exploit as part of its offensive cyber operations. In 2017, the NSA discovered that the software had been stolen by a group of hackers known as [The Shadow Brokers](https://en.wikipedia.org/wiki/The_Shadow_Brokers "The Shadow Brokers"). Microsoft was subsequently informed of this and released security updates in March 2017 [patching](https://en.wikipedia.org/wiki/Patch_\(computing\) "Patch (computing)") the vulnerability. While this was happening, the hacker group attempted to auction off the software, but did not succeed in finding a buyer. EternalBlue was then released publicly on April 14, 2017.[[5]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-ars-5)

On May 12, 2017, a [computer worm](https://en.wikipedia.org/wiki/Computer_worm "Computer worm") in the form of [ransomware](https://en.wikipedia.org/wiki/Ransomware "Ransomware"), nicknamed [WannaCry](https://en.wikipedia.org/wiki/WannaCry_ransomware "WannaCry ransomware"), used the EternalBlue exploit to attack computers using Windows that had not received the latest system updates removing the vulnerability.[[5]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-ars-5)[[7]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-7)[[8]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-8)[[9]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-:0-9)[[10]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-10)[[11]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-Wired_5-7-11) On June 27, 2017, the exploit was again used to help carry out the [2017 NotPetya cyberattack](https://en.wikipedia.org/wiki/2017_NotPetya_cyberattack "2017 NotPetya cyberattack") on more vulnerable computers.[[12]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-12)

The exploit was also reported to have been used since March 2016 by the Chinese hacking group [Buckeye (APT3)](https://en.wikipedia.org/wiki/Advanced_persistent_threat#APT_groups "Advanced persistent threat"), after they likely found and re-purposed the software,[[11]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-Wired_5-7-11) as well as reported to have been used as part of the Retefe banking [trojan](https://en.wikipedia.org/wiki/Trojan_horse_\(computing\) "Trojan horse (computing)") since at least September 5, 2017.[[13]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-13)

## Details

EternalBlue exploits a vulnerability in [Microsoft](https://en.wikipedia.org/wiki/Microsoft "Microsoft")'s implementation of the [Server Message Block](https://en.wikipedia.org/wiki/Server_Message_Block "Server Message Block") (SMB) protocol. This vulnerability is denoted by entry [CVE](https://en.wikipedia.org/wiki/CVE_\(identifier\) "CVE (identifier)")-[2017-0144](https://nvd.nist.gov/vuln/detail/CVE-2017-0144)[[14]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-14)[[15]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-15) in the [Common Vulnerabilities and Exposures](https://en.wikipedia.org/wiki/Common_Vulnerabilities_and_Exposures "Common Vulnerabilities and Exposures") (CVE) catalog. The vulnerability exists because the SMB version 1 (SMBv1) server in various versions of [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows "Microsoft Windows") mishandles specially crafted packets from remote attackers, allowing them to remotely execute code on the target computer.[[16]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-16)

The NSA did not alert Microsoft about the vulnerability, holding onto it for more than five years before the breach forced its hand. The agency then warned Microsoft after learning about EternalBlue's possible theft, allowing the company to prepare a software patch issued in March 2017,[[6]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-:2-6) after delaying its regular release of security [patches](https://en.wikipedia.org/wiki/Patch_\(computing\) "Patch (computing)") in February 2017.[[17]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-verge-nsapatch-17) On [Tuesday](https://en.wikipedia.org/wiki/Patch_Tuesday "Patch Tuesday"), March 14, 2017, Microsoft issued security bulletin MS17-010,[[18]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-microsoft.com-18) which detailed the flaw and announced that [patches](https://en.wikipedia.org/wiki/Security_patch "Security patch") had been released for all Windows versions supported at that time, including [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista "Windows Vista"), [Windows 7](https://en.wikipedia.org/wiki/Windows_7 "Windows 7"), [Windows 8.1](https://en.wikipedia.org/wiki/Windows_8.1 "Windows 8.1"), [Windows 10](https://en.wikipedia.org/wiki/Windows_10 "Windows 10"), [Windows Server 2008](https://en.wikipedia.org/wiki/Windows_Server_2008 "Windows Server 2008"), [Windows Server 2008 R2](https://en.wikipedia.org/wiki/Windows_Server_2008_R2 "Windows Server 2008 R2"), [Windows Server 2012](https://en.wikipedia.org/wiki/Windows_Server_2012 "Windows Server 2012"), [Windows Server 2012 R2](https://en.wikipedia.org/wiki/Windows_Server_2012_R2 "Windows Server 2012 R2"), and [Windows Server 2016](https://en.wikipedia.org/wiki/Windows_Server_2016 "Windows Server 2016").[[19]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-19)[[20]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-20)

[The Shadow Brokers](https://en.wikipedia.org/wiki/The_Shadow_Brokers "The Shadow Brokers") publicly released the EternalBlue exploit code on April 14, 2017, along with several other NSA hacking tools.[[5]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-ars-5)

Many Windows users had not installed the Microsoft patches when, on May 12, 2017, the [WannaCry ransomware attack](https://en.wikipedia.org/wiki/WannaCry_ransomware_attack "WannaCry ransomware attack") started using the EternalBlue vulnerability to spread.[[21]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-21)[[22]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-22) The next day (May 13, 2017), Microsoft released emergency security patches for unsupported versions, including [Windows XP](https://en.wikipedia.org/wiki/Windows_XP "Windows XP"), [Windows 8](https://en.wikipedia.org/wiki/Windows_8 "Windows 8"), and [Windows Server 2003](https://en.wikipedia.org/wiki/Windows_Server_2003 "Windows Server 2003").[[23]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-23)[[24]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-24)

In February 2018, EternalBlue was [ported](https://en.wikipedia.org/wiki/Porting "Porting") to all Windows operating systems released since [Windows 2000](https://en.wikipedia.org/wiki/Windows_2000 "Windows 2000") by [RiskSense](https://en.wikipedia.org/wiki/RiskSense?action=edit&redlink=1 "RiskSense (page does not exist)") security researcher Sean Dillon. EternalChampion and EternalRomance, two other exploits originally developed by the NSA and leaked by [The Shadow Brokers](https://en.wikipedia.org/wiki/The_Shadow_Brokers "The Shadow Brokers"), were also ported during the same event and made available as [open-source](https://en.wikipedia.org/wiki/Open-source_model "Open-source model") [Metasploit](https://en.wikipedia.org/wiki/Metasploit "Metasploit") modules.[[25]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-25)

By late 2018, millions of systems remained vulnerable to EternalBlue, leading to millions of dollars in damages primarily caused by ransomware worms. Following the massive impact of [WannaCry](https://en.wikipedia.org/wiki/WannaCry "WannaCry"), which caused over $8 billion in damages across 150 countries, later outbreaks such as [NotPetya](https://en.wikipedia.org/wiki/NotPetya "NotPetya") and BadRabbit also propagated using EternalBlue as either an initial compromise vector or a method of lateral movement.[[26]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-26)

### City of Baltimore cyberattack

In May 2019, the city of [Baltimore](https://en.wikipedia.org/wiki/Baltimore "Baltimore") struggled with a [cyberattack](https://en.wikipedia.org/wiki/2019_Baltimore_ransomware_attack "2019 Baltimore ransomware attack") by digital extortionists; the attack froze thousands of computers, shut down email, and disrupted real estate sales, water bills, health alerts, and many other services. Nicole Perlroth, writing for _[The New York Times](https://en.wikipedia.org/wiki/The_New_York_Times "The New York Times")_, initially attributed this attack to EternalBlue;[[27]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-27) however, in a February 2021 book on the cyber arms market, Perlroth clarified that EternalBlue was not responsible for the Baltimore cyberattack, while criticizing others for pointing out "the technical detail that in this particular case, the ransomware attack had not spread with EternalBlue".[[28]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-28)

As a result of the cyberattack, four Baltimore City chief information officers were fired or resigned; two left while under investigation.[[29]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-29) Some security researchers argued that responsibility for the breach lay with the city for failing to update its computers. Security consultant Rob Graham noted: "If an organization has substantial numbers of Windows machines that have gone 2 years without patches, then that’s squarely the fault of the organization, not EternalBlue."[[30]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-30)

### Russian computers hacked

First appearing in February 2017, an updated version of EternalBlue emerged in May 2017, according to a [Kaspersky](https://en.wikipedia.org/wiki/Kaspersky_Lab "Kaspersky Lab") forum report. It affected internal systems at the [Ministry of Internal Affairs of Russia](https://en.wikipedia.org/wiki/Ministry_of_Internal_Affairs_\(Russia\) "Ministry of Internal Affairs (Russia)") and computers across several regions, including Tatarstan. The [WannaCry ransomware](https://en.wikipedia.org/wiki/WannaCry_ransomware_attack "WannaCry ransomware attack") (also known as WCry or WannaCryptor) encrypted user files, appended the '.WNCRY' extension, and demanded payment in [bitcoins](https://en.wikipedia.org/wiki/Bitcoin "Bitcoin") for a decryption tool under threat of permanent file deletion. Worldwide, over 36,000 computers were infected, with the majority located in Russia, Ukraine, and Taiwan, according to cybersecurity firm [Avast](https://en.wikipedia.org/wiki/Avast "Avast").[[31]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-31)[[32]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-32)

## Responsibility

Following the WannaCry attack, Microsoft took primary responsibility for addressing the vulnerability, but criticized U.S. intelligence agencies like the NSA and [CIA](https://en.wikipedia.org/wiki/Central_Intelligence_Agency "Central Intelligence Agency") for stockpiling vulnerabilities rather than disclosing them. Microsoft stated that "an equivalent scenario with conventional weapons would be the [U.S. military](https://en.wikipedia.org/wiki/United_States_Armed_Forces "United States Armed Forces") having some of its [Tomahawk missiles](https://en.wikipedia.org/wiki/Tomahawk_\(missile_family\) "Tomahawk (missile family)") stolen".[[33]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-:1-33) This stockpiling strategy prevented Microsoft from identifying and patching the exploit earlier.[[33]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-:1-33)[[34]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-34) However, commentators including Alex Abdo of [Columbia University](https://en.wikipedia.org/wiki/Columbia_University "Columbia University")'s Knight First Amendment Institute criticized Microsoft for shifting blame to the NSA, arguing the company should remain accountable for releasing a vulnerable product.[[35]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-35) The company was also faulted for initially limiting the patch to actively supported Windows versions and paying Extended Support customers, leaving entities like the UK's NHS vulnerable. A month later, Microsoft took the unusual step of releasing free patches for legacy systems back to Windows XP.[[36]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-36)

## EternalRocks

**EternalRocks** (also known as **MicroBotMassiveNet**) is a [computer worm](https://en.wikipedia.org/wiki/Computer_worm "Computer worm") that infects Microsoft Windows systems using seven NSA-developed exploits.[[37]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-cnet-37) In comparison, WannaCry utilized only two, leading researchers to consider EternalRocks potentially more dangerous.[[38]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-38) The worm was first identified using a [honeypot](https://en.wikipedia.org/wiki/Honeypot_\(computing\) "Honeypot (computing)").[[39]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-39)

### Infection

EternalRocks initially installs [Tor](https://en.wikipedia.org/wiki/Tor_\(anonymity_network\) "Tor (anonymity network)") to communicate with command-and-control servers covertly. After a 24-hour incubation period,[[37]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-cnet-37) it downloads executable payloads and replicates across host machines.

To avoid early detection, the malware claims to be WannaCry in its file properties. However, unlike WannaCry, EternalRocks does not contain a [kill switch](https://en.wikipedia.org/wiki/Kill_switch#Software "Kill switch") or deliver a ransomware payload.[[37]](https://en.wikipedia.org/wiki/EternalBlue#cite_note-cnet-37)
