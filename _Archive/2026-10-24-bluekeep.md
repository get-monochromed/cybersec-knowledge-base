## Mechanism

The RDP protocol uses "virtual channels", configured before authentication, as a data path between the client and server for providing extensions. RDP 5.1 defines 32 "static" virtual channels, and "dynamic" virtual channels are contained within one of these static channels. If a server binds the virtual channel "MS_T120" (a channel for which there is no legitimate reason for a client to connect to) with a static channel other than 31, [heap corruption](https://en.wikipedia.org/wiki/Heap_corruption "Heap corruption") occurs that allows for [arbitrary code execution](https://en.wikipedia.org/wiki/Arbitrary_code_execution "Arbitrary code execution") at the system level.[[24]](https://en.wikipedia.org/wiki/BlueKeep#cite_note-McAfee_Blogs-2019-24)

[Windows XP](https://en.wikipedia.org/wiki/Windows_XP "Windows XP"), [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista "Windows Vista"), [Windows 7](https://en.wikipedia.org/wiki/Windows_7 "Windows 7"), [Windows Server 2003](https://en.wikipedia.org/wiki/Windows_Server_2003 "Windows Server 2003"), [Windows Server 2008](https://en.wikipedia.org/wiki/Windows_Server_2008 "Windows Server 2008"), and [Windows Server 2008 R2](https://en.wikipedia.org/wiki/Windows_Server_2008_R2 "Windows Server 2008 R2") were named by Microsoft as being vulnerable to this attack. Versions newer than 7, such as [Windows 8](https://en.wikipedia.org/wiki/Windows_8 "Windows 8"), [Windows 10](https://en.wikipedia.org/wiki/Windows_10 "Windows 10") and [Windows 11](https://en.wikipedia.org/wiki/Windows_11 "Windows 11"), were not affected. The [Cybersecurity and Infrastructure Security Agency](https://en.wikipedia.org/wiki/Cybersecurity_and_Infrastructure_Security_Agency "Cybersecurity and Infrastructure Security Agency") stated that it had also successfully achieved code execution via the vulnerability on [Windows 2000](https://en.wikipedia.org/wiki/Windows_2000 "Windows 2000").[[25]](https://en.wikipedia.org/wiki/BlueKeep#cite_note-25)

## Mitigation

Microsoft released patches for the vulnerability on 14 May 2019, for [Windows XP](https://en.wikipedia.org/wiki/Windows_XP "Windows XP"), [Windows Vista](https://en.wikipedia.org/wiki/Windows_Vista "Windows Vista"), [Windows 7](https://en.wikipedia.org/wiki/Windows_7 "Windows 7"), [Windows Server 2003](https://en.wikipedia.org/wiki/Windows_Server_2003 "Windows Server 2003"), [Windows Server 2008](https://en.wikipedia.org/wiki/Windows_Server_2008 "Windows Server 2008"), and [Windows Server 2008 R2](https://en.wikipedia.org/wiki/Windows_Server_2008_R2 "Windows Server 2008 R2"). This included versions of Windows that have reached their [end-of-life](https://en.wikipedia.org/wiki/End-of-life_\(product\) "End-of-life (product)") (such as Vista, XP, and Server 2003) and thus are no longer eligible for security updates.[[8]](https://en.wikipedia.org/wiki/BlueKeep#cite_note-Goodin-2019a-8) The patch forces the aforementioned "MS_T120" channel to always be bound to 31 even if requested otherwise by an RDP server.[[24]](https://en.wikipedia.org/wiki/BlueKeep#cite_note-McAfee_Blogs-2019-24)

The NSA recommended additional measures, such as disabling [Remote Desktop Services](https://en.wikipedia.org/wiki/Remote_Desktop_Services "Remote Desktop Services") and its associated [port](https://en.wikipedia.org/wiki/Port_\(computer_networking\) "Port (computer networking)") ([TCP](https://en.wikipedia.org/wiki/Transmission_Control_Protocol "Transmission Control Protocol") 3389) if it is not being used, and requiring [Network Level Authentication](https://en.wikipedia.org/wiki/Network_Level_Authentication "Network Level Authentication") (NLA) for RDP.[[26]](https://en.wikipedia.org/wiki/BlueKeep#cite_note-26) According to computer security company [Sophos](https://en.wikipedia.org/wiki/Sophos "Sophos"), two-factor authentication may make the RDP issue less of a vulnerability. However, the best protection is to take RDP off the Internet: switch RDP off if not needed and, if needed, make RDP accessible only via a [VPN](https://en.wikipedia.org/wiki/Virtual_private_network "Virtual private network").[[27]](https://en.wikipedia.org/wiki/BlueKeep#cite_note-27)
