# Defensive Operations

Detecting, investigating and responding to attacks. This is where controls become outcomes.

## The function

- [[Security Operations Centre]] — who does the work, and how it is organised
- [[SIEM]] — the data platform
- [[SOAR]] — automation and response
- [[Threat Hunting]] — proactive search for what detection missed
- [[Peer List Poisoning]] — how a P2P botnet is taken over by controlling its peer discovery
- [[Incident Response]] — the process when something is real
- [[Digital Forensics]] — evidence and root cause
- [[Sigma Rules]] — detection-as-code, vendor-neutral rule format
