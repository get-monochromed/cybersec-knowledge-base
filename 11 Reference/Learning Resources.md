# Learning Resources

## Hands-on labs

- **PortSwigger Web Security Academy** — free, best web security labs anywhere.
- **TryHackMe** — guided paths, good for foundations and blue team.
- **Hack The Box** — machines, Pro Labs, Academy; harder, less guidance.
- **Blue Team Labs Online / LetsDefend / CyberDefenders** — SOC/DFIR practice.
- **VulnHub / Vulnlab** — offline vulnerable machines.
- **PicoCTF / CTFtime** — competitions; CTFtime lists everything.
- **Detection Engineering / Atomic Red Team** — test detections locally.

## Home lab

- Proxmox or KVM host: Kali/Parrot attacker, Windows AD domain (DC + workstation), Linux servers, pfSense/OPNsense, Security Onion or Wazuh+ELK for blue team.
- Snapshot aggressively; isolate from your real network.
- Document each exercise as a note here — that is how this vault grows.

## Reading

- **Web Application Hacker's Handbook** (Stuttard & Pinto) — dated but foundational.
- **The Tangled Web** (Zalewski) — browser security model.
- **Practical Malware Analysis** (Sikorski & Honig).
- **The Art of Memory Forensics** (Ligh et al.).
- **Security Engineering** (Anderson) — free online, the best broad text.
- **Threat Modeling: Designing for Security** (Shostack).
- **Crafting Intrusion Detection** / detection engineering blogs.
- **NIST SP 800-53/61/207, CIS Benchmarks, OWASP guides, MITRE ATT&CK** — primary sources, free.

## Staying current

- CISA advisories + KEV catalogue ([[Vulnerability Management]]).
- Vendor research blogs (Project Zero, MSRC, Talos, Unit 42, Mandiant, CrowdStrike).
- Krebs, Risky Business, Darknet Diaries (context, not technique).
- Conference talks: DEF CON, Black Hat, BSides, Troopers, BlueHat.

## Habits that compound

1. Write up every lab and incident in this vault ([[README]]).
2. Rebuild a detection rule for each technique you learn ([[Purple Teaming]]).
3. Read the primary source, not the summary.
4. Teach it — a note you cannot explain is a note you do not understand.
