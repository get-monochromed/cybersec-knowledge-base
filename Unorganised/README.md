# Unorganised — inbox

Drop raw material here and nothing else. Braindumps, lecture notes, copied web clips, half-remembered command lines, screenshots. No formatting required.

Ingest with:

> "Ingest Unorganised" — or `/kb:ingest`

Pi reads everything here, prints a filing plan, then files the knowledge into the section folders with links. Sources are moved to `_Archive/` afterwards, never deleted.

Housekeeping: keep this folder empty at the end of a session. If something has been sitting here for weeks, it either gets ingested or explicitly marked `status: parked`.
